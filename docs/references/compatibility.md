# Compatibility

| Area | Baseline |
| --- | --- |
| .NET runtime services | .NET 6 or .NET 8 depending on repository. |
| Documentation portal | Node.js 20+, Docusaurus 3. |
| WinCC controls | Windows, .NET Framework build tools, WebView2 Runtime. |
| TwinCAT assets | Beckhoff TwinCAT tooling and compatible runtime. |
| HMI extensions | Beckhoff TwinCAT HMI tooling. |
