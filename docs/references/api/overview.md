# API References

This section contains API references for the TechIndustry repositories.

Reference targets:

- DocFX for .NET projects: namespaces, types, constructors, methods, properties, events and XML documentation comments when present.
- Protobuf inventory for gRPC contracts.
- TwinCAT PLC inventory from `.TcPOU`, `.TcDUT` and `.TcGVL` files.
- TwinCAT HMI inventory from manifest and description files.

Use these pages when you need source-level details beyond the project guides and examples.
