# Naming Conventions

Repository naming follows the implementation domain:

- `twincat-*` for Beckhoff TwinCAT projects.
- `simatic-*` for Siemens/SIMATIC projects.
- `*-dotnet` for reusable .NET libraries.
- descriptive runtime names for services such as `opcua-bridge`.

Packages use PascalCase IDs under the `TechIndustry` namespace.
