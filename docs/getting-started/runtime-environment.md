# Runtime Environment

Before using a component, confirm the target environment has the required runtime services and access.

## Runtime checklist

- GitHub Packages access for NuGet libraries.
- GHCR access for containerized services.
- Release artifact access for Windows deployments.
- Secret storage for credentials, connection strings and certificates.
- Network access to PLC routes, OPC UA endpoints, brokers, databases or cloud ingestion services.

Use the library quickstart to validate a minimal scenario first, then move the same configuration model into the target environment.
