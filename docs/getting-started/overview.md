# Getting Started

TechIndustry projects cover three main layers:

- **Reusable libraries** published as NuGet packages through GitHub Packages.
- **Runtime services** published as GHCR container images or Windows release artifacts.
- **Industrial integration assets** for TwinCAT, OPC UA, SIMATIC WinCC and TwinCAT HMI.

Start from the project map, then choose the quickstart for the repository you need.

## Common Requirements

- Access to the `TechIndustryX` GitHub organization for private packages, containers or releases.
- .NET runtime or SDK when consuming .NET packages.
- Docker or a container platform when consuming runtime services from GHCR.
- Beckhoff or Siemens tooling where the component is installed into an industrial IDE/runtime.
- Access to the required plant endpoints, brokers, PLC routes, OPC UA endpoints or cloud resources.
