# Guides

Recommended guide path:

1. Select TwinCAT symbols or telemetry groups.
2. Configure the streaming destination, such as MQTT or Azure ingestion.
3. Deploy the runtime component from the container image or approved Windows release.
4. Connect the dashboard or subscriber.
5. Validate latency, timestamp quality and reconnect behavior.

See [Release Process](../../guides/release-process.md) and [GHCR Containers](../../guides/ghcr-containers.md).
