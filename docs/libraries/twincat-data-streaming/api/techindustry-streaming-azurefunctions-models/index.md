# TechIndustry.Streaming.AzureFunctions.Models

This namespace contains 3 public API types.

## Types

- [InputMetric](./inputmetric.md) _class_ - Represents a single metric data point received from a TwinCAT data stream, carrying a stream name and arbitrary key/value fields.
- [InputPubMessage](./inputpubmessage.md) _class_ - Represents an Azure Web PubSub message payload that carries a target hub, content, and optional additional data.
- [InputQuery](./inputquery.md) _class_ - Represents a Kusto (KQL) query request with an optional set of named parameters.
