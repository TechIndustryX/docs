# Azure.Monitor.Collector

This namespace contains 2 public API types.

## Types

- [LogAnalyticsCollector](./loganalyticscollector.md) _class_ - Sends JSON metric batches to Azure Monitor Log Analytics using the legacy HTTP Data Collector API (2016-04-01), signing each request with the configured workspace key.
- [LogAnalyticsOptions](./loganalyticsoptions.md) _class_ - Configuration options for the legacy Azure Monitor Log Analytics HTTP Data Collector API (2016-04-01).
