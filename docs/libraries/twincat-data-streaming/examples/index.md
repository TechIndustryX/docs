# TwinCAT Data Streaming Examples

These examples follow the TwinCAT reader, MQTT forwarder, Azure Functions and demo dashboard implementation.

- [TwinCAT Symbol Reader](./twincat-symbol-reader.md): subscribe to live symbols.
- [MQTT Forwarder](./mqtt-forwarder.md): batch, transform and publish values.
- [Azure Functions Ingestion](./azure-functions-ingestion.md): receive metrics from HTTP or Event Hub.
- [Log Analytics Query](./log-analytics-query.md): query historical telemetry.
- [Realtime Dashboard](./realtime-dashboard.md): publish live messages to Web PubSub and the UI.
- [Simulator to Cloud](./simulator-to-cloud.md): validate the cloud path without a machine.
