# Guides

Recommended guide path:

1. Choose the OPC UA endpoint policy and certificate strategy.
2. Configure namespace exposure and plugin connectivity.
3. Run the bridge from the container image or approved Windows release.
4. Validate client access, subscriptions and plugin lifecycle in the target network.

See [GHCR Containers](../../guides/ghcr-containers.md) and [Release Process](../../guides/release-process.md).
