# OPC UA Bridge Examples

These examples follow the real server host, gRPC plugin service and `Plugin.Echo` implementation.

- [Run Server](./run-server.md): start the OPC UA/gRPC host.
- [Echo Plugin](./echo-plugin.md): connect a plugin process to the bridge.
- [Dynamic Namespace](./dynamic-namespace.md): configure a node-set document at runtime.
- [Node Read/Write](./node-read-write.md): read and write plugin-owned node values.
- [Write and Method Interception](./write-and-method-interception.md): handle OPC UA write and method activity in the plugin.
- [Edge Container](./edge-container.md): package the bridge for distributed runtime scenarios.
