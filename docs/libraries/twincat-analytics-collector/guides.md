# Guides

Recommended guide path:

1. Choose the TwinCAT source and tag set.
2. Configure MQTT, HSDS or file storage outputs.
3. Run the collector image in the target environment.
4. Validate sample frequency, payload shape and retention before expanding scope.

See [GitHub Packages](../../guides/github-packages.md) and [GHCR Containers](../../guides/ghcr-containers.md).
