# TwinCAT HMI UI Controls Examples

These examples show how to use the controls in TwinCAT HMI screens, starting from the sample contents included in the repository.

## Learning Path

1. [Basic Controls](./basic-controls.md): place switches, LEDs, numeric boxes and icon buttons.
2. [Gauge Zones](./gauge-zones.md): show process values with warning and alarm ranges.
3. [Live SVG](./live-svg.md): bind machine state to an SVG representation.
4. [Slide Panel](./slide-panel.md): build collapsible operator panels.
5. [Custom Function](./custom-function.md): convert values for bindings.
