# TwinCAT HMI UI Controls Examples

These examples follow the `TcHmiSample` project and the shipped control descriptions.

- [Basic Controls](./basic-controls.md): use operator controls such as button, switch, numeric input and popover.
- [Gauge Zones](./gauge-zones.md): configure process value zones and labels.
- [Live SVG](./live-svg.md): bind SVG elements to HMI state and handle clicks.
- [Slide Panel](./slide-panel.md): compose dynamic card-based screens.
- [Custom Function](./custom-function.md): register and use a TwinCAT HMI helper function.
