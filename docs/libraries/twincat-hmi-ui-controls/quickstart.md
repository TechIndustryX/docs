# TwinCAT HMI UI Controls Quickstart

Use TwinCAT HMI UI Controls to add reusable TechIndustry controls to a TwinCAT HMI project.

## 1. Install the extension package

Install the delivered TwinCAT HMI package on the engineering workstation. Restart TwinCAT HMI Engineering if the controls do not appear immediately in the toolbox.

## 2. Add controls to a view

Open the target HMI project, drag the required TechIndustry controls onto the view and apply the project theme.

## 3. Bind data and events

Bind control properties to HMI symbols, PLC symbols or view-model data. Configure command events for operator actions such as acknowledge, setpoint update or navigation.

## 4. Validate in runtime

Run the HMI locally or on the target panel. Check scaling, touch behavior, disabled states and live data updates with realistic operator permissions.
