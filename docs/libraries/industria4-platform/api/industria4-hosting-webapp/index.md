# Industria4.Hosting.WebApp

This namespace contains 4 public API types.

## Types

- [App](./app.md) _class_ - Root Blazor component for the Hosting WebApp client, responsible for bootstrapping modules and routing.
- [HostingOptions](./hostingoptions.md) _class_ - Configuration options for the Industria4 hosting web application.
- [MessagingService](./messagingservice.md) _class_
- [Program](./program.md) _class_ - Blazor WebAssembly entry point for the Hosting WebApp client, responsible for loading the license, configuring services, and starting the host.
