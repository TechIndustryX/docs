# Industria4.Identity.WebApi.Controllers

This namespace contains 5 public API types.

## Types

- [AccountController](./accountcontroller.md) _class_ - MVC controller that handles account login and logout flows for IdentityServer4.
- [AuditlogController](./auditlogcontroller.md) _class_ - API controller exposing read-only OData-queryable audit log entries.
- [HomeController](./homecontroller.md) _class_ - Default MVC controller handling the home page and error display.
- [RoleController](./rolecontroller.md) _class_ - API controller exposing read-only OData-queryable roles.
- [UserController](./usercontroller.md) _class_ - API controller exposing read-only OData-queryable users and single-user lookup.
