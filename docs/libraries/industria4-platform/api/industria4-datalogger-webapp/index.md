# Industria4.DataLogger.WebApp

This namespace contains 10 public API types.

## Types

- [DataLoggerInfluxDbOptions](./dataloggerinfluxdboptions.md) _class_ - Connection options for a single InfluxDB instance.
- [DataLoggerLanguageOptions](./dataloggerlanguageoptions.md) _class_ - Dictionary of field-name to display-label overrides for a single culture (case-insensitive).
- [DataLoggerLanguagesOptions](./dataloggerlanguagesoptions.md) _class_ - Dictionary of per-culture field-label options, keyed by culture name (case-insensitive).
- [DataLoggerMeasurementOptions](./dataloggermeasurementoptions.md) _class_ - Display and routing options for a single InfluxDB measurement.
- [DataLoggerOptions](./dataloggeroptions.md) _class_ - Top-level configuration options for the DataLogger web application.
- [DataLoggerStyleOptions](./dataloggerstyleoptions.md) _class_ - Visual style overrides for a matched field value.
- [DataLoggerStylesOptions](./dataloggerstylesoptions.md) _class_ - Dictionary of style options keyed by field match expression.
- [MatchKey](./matchkey.md) _struct_ - A parsed field-matching key that optionally includes a comparison operator and value.
- [MatchKeyExtensions](./matchkeyextensions.md) _class_ - Extension methods for searching collections keyed by using wildcard/value matching.
- [StartupService](./startupservice.md) _class_ - Startup service that registers DataLogger web-application dependencies and configuration.
