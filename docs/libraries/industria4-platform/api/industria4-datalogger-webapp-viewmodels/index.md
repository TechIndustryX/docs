# Industria4.DataLogger.WebApp.ViewModels

This namespace contains 6 public API types.

## Types

- [DataLoggerViewModel](./dataloggerviewmodel.md) _class_ - View model that drives the DataLogger Blazor page, querying InfluxDB and presenting paginated measurement data.
- [Field](./field.md) _class_ - Represents a queryable field from an InfluxDB measurement.
- [FieldResult](./fieldresult.md) _class_ - A single result set from an InfluxDB query response.
- [FieldsResults](./fieldsresults.md) _class_ - Container for the raw InfluxDB query response envelope.
- [MeasurementItem](./measurementitem.md) _class_ - Represents a single row from an InfluxDB measurement with optional localization and style overrides applied.
- [Series](./series.md) _class_ - A single InfluxDB measurement series within a query result.
