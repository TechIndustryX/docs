# Industria4.Transformation

This namespace contains 3 public API types.

## Types

- [DomainExcelExporter](./domainexcelexporter.md) _class_ - Concrete Excel exporter that maps entity property descriptors to columns, with optional filtering and language-dictionary support.
- [DomainExcelExporterBase](./domainexcelexporterbase.md) _class_ - Base class for Excel-based import/export of domain entities, supporting chunked batch operations.
- [LanguagesExcelExporter](./languagesexcelexporter.md) _class_ - Exports and imports fields on entities to and from Excel worksheets.
