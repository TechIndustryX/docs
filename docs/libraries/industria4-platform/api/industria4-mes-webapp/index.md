# Industria4.Mes.WebApp

This namespace contains 7 public API types.

## Types

- [MesGridAdditionalColumnOptions](./mesgridadditionalcolumnoptions.md) _class_ - Represents the localised label map for a single additional grid column (maps culture code to display label).
- [MesGridDefaultSortColumnDirection](./mesgriddefaultsortcolumndirection.md) _enum_ - Specifies the sort direction for the work-order grid default sort.
- [MesGridDefaultSortColumnOptions](./mesgriddefaultsortcolumnoptions.md) _class_ - Specifies the default sort column name and direction for the work-order grid.
- [MesGridOptions](./mesgridoptions.md) _class_ - Configuration for the work-order grid columns and sort order.
- [MesOptions](./mesoptions.md) _class_ - Runtime configuration options for the MES WebApp UI module.
- [StartupService](./startupservice.md) _class_ - Startup service that registers MES WebApp view models, HTTP client, and the MES Blazor module. Only runs in client (Blazor WebAssembly) contexts.
- [WorkOrderPriorityMode](./workorderprioritymode.md) _enum_ - Specifies how work orders are sorted by priority in the MES WebApp grid.
