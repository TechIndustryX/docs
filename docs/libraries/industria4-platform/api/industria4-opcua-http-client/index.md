# Industria4.OpcUa.Http.Client

- [ReadResponseModel](./readresponsemodel.md) _class_ - HTTP response model containing the read values for OPC-UA nodes.
- [WriteModel](./writemodel.md) _class_ - HTTP request model for writing typed values to OPC-UA nodes.
