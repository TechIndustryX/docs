# Industria4.Identity.DomainModel.Events

This namespace contains 6 public API types.

## Types

- [BaseUserEvent](./baseuserevent.md) _class_ - Abstract base for all user-related Identity audit events.
- [ChangedRoleEvent](./changedroleevent.md) _class_ - Event raised when a role is created or updated.
- [ChangedUserEvent](./changeduserevent.md) _class_ - Event raised when a user account is created or updated.
- [DeletedRoleEvent](./deletedroleevent.md) _class_ - Event raised when a role is deleted.
- [DeletedUserEvent](./deleteduserevent.md) _class_ - Event raised when a user account is deleted.
- [UnauthorizedEvent](./unauthorizedevent.md) _class_ - Event raised when an unauthorized access attempt is detected.
