# Industria4.Web.Forms.Globalization.Components

This namespace contains 5 public API types.

## Types

- [LanguageComponentBase](./languagecomponentbase.md) _class_ - Base Blazor component that monitors changes and re-renders on language switch.
- [LanguageDictionaryInput](./languagedictionaryinput.md) _class_ - Blazor input component for editing a value, with an integrated dialog to manage individual language entries.
- [LanguageObjectRowInput](./languageobjectrowinput.md) _class_ - Row-input component that automatically resolves its label from resource types and refreshes when the active language changes.
- [LanguageRowInput&lt;TItem&gt;](./languagerowinput.md) _class_ - Generic row-input component that resolves its label from resource types and refreshes when the active language changes. The model item type.
- [LanguageTransformation](./languagetransformation.md) _class_ - Blazor component providing export and import actions for language resource transformations.
