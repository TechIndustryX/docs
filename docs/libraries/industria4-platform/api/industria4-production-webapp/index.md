# Industria4.Production.WebApp

This namespace contains 2 public API types.

## Types

- [ProductionOptions](./productionoptions.md) _class_ - Runtime configuration options for the Production WebApp module (additional display fields, OpcUa support flag).
- [StartupService](./startupservice.md) _class_ - Startup service that registers Production WebApp view models, HTTP clients, and Blazor modules. Only runs in client (browser-side Blazor) contexts.
