# System.Linq

This namespace contains 3 public API types.

## Types

- [LinqExtensions](./linqextensions.md) _class_ - Extension methods that add OData-specific LINQ operators (`$filter` and `$orderby` raw strings) to pipelines.
- [QueryableExtensions](./queryableextensions.md) _class_ - Extension methods for that add filtering helpers operating on expressions.
- [QueryableExtensions](./queryableextensions-2.md) _class_ - Extension methods for that apply dynamic filtering and sorting by property name.
