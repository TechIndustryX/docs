# Industria4.Web.Authorization

This namespace contains 3 public API types.

## Types

- [FallbackAuthorizationPolicyProvider](./fallbackauthorizationpolicyprovider.md) _class_ - Authorization policy provider that returns a configurable fallback policy when a named policy is not registered.
- [PolicyItemOptions](./policyitemoptions.md) _class_ - Requirements for a single named authorization policy.
- [PolicyOptions](./policyoptions.md) _class_ - Top-level authorization policy configuration that maps policy names to their requirements.
