# Industria4.OpcUa.Comunication.Core

This namespace contains 6 public API types.

## Types

- [ArrayItemOptions](./arrayitemoptions.md) _class_ - Configures the array-item rewriting rules applied to write operations.
- [CoreModule](./coremodule.md) _class_ - Hosting module that represents the OPC-UA core middleware component.
- [CoreOpcUaMiddleware](./coreopcuamiddleware.md) _class_ - Middleware that pre-processes write operations: applies array-item transforms and injects metadata node values.
- [CoreOptions](./coreoptions.md) _class_ - Configuration options for the OPC-UA core middleware.
- [MetadataNodeId](./metadatanodeid.md) _class_ - Maps a metadata key to an OPC-UA node and its expected data type.
- [Startup](./startup.md) _class_ - Startup service that registers the core OPC-UA middleware and binds from configuration.
