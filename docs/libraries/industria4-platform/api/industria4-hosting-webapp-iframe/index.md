# Industria4.Hosting.WebApp.IFrame

This namespace contains 3 public API types.

## Types

- [FrameLink](./framelink.md) _class_ - Defines a single external link displayed as an IFrame panel in the hosting web app.
- [FrameOptions](./frameoptions.md) _class_ - A named dictionary of entries that configure IFrame navigation links.
- [StartupService](./startupservice.md) _class_ - Registers the IFrame module services (menu entries, routing, policies) when running in a client context.
