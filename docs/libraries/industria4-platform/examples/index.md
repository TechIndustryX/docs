# Industria4 Platform Examples

These examples are based on the first consumers of the platform architecture: module startup services, hosted modules, CQRS handlers and Web API modules.

- [Local Composition](./local-composition.md): run the platform with local dependencies.
- [Module Hosting](./module-hosting.md): load modules through the hosting layer.
- [Identity Users and Roles](./identity-users-roles.md): handle users, roles, claims and audit events.
- [CQRS Command Flow](./cqrs-command-flow.md): understand command, validation and completion events.
- [Recipes and MES](./recipes-and-mes.md): connect operational models, recipes and work orders.
- [OPC UA Data Logger](./opcua-data-logger.md): register OPC UA middleware and data-logging modules.
- [Production Composition](./production-composition.md): define compositions and deployments.
